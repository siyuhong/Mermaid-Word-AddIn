Mermaid Diagram Word Add-in

Write Mermaid code, preview diagrams, and insert them into Word documents. An internet connection is required. You do not need to install Node.js or development certificates.

Download the add-in manifest (manifest.xml)

This version is installed by sideloading for testing and evaluation. Available installation options depend on your Office version and organization policies.

Word on the web

  1. Download manifest.xml using the link above.
  2. Open an editable document in Word on the web.
  3. Go to Home → Add-ins → More Settings → Upload My Add-in and upload the manifest file. Menu labels may vary by version.
  4. Open Mermaid Editor from the Insert tab.

You may need to upload the manifest again after switching browsers or clearing browser storage. This does not automatically install the add-in in desktop Word.

Word on Windows

  1. Create a folder for the manifest and place the downloaded manifest.xml in it.
  2. Share the folder using the Sharing tab in its Windows properties. Note the actual UNC path, such as \\YourComputerName\MermaidAddin.
  3. In Word, go to File → Options → Trust Center → Trust Center Settings → Trusted Add-in Catalogs.
  4. Enter the UNC path, select Add catalog, and check Show in Menu. Close and reopen Word.
  5. In the Add-ins / My Add-ins dialog, open the Shared Folder tab, select MermaidSupport, and add it.
  6. Open Mermaid Editor from the Insert tab.

Grant read access only to accounts that need to use the folder. If your organization blocks shared folders or sideloading, contact your administrator.

Insert and edit diagrams

  1. Enter your code or use the default example, then wait for the preview to finish.
  2. Place the Word cursor where you want the diagram and click Insert | Replace. Any currently selected text or image will be replaced.
  3. To edit a diagram, select an image inserted by this add-in and click Edit Selected to load its source code.
  4. After making changes, keep the original image selected and click Insert | Replace to update it.

The Mermaid source is stored in the image's alternative text and saved with the document. Keep this information intact to edit the diagram again.
